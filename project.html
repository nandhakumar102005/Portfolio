Food Wastage Management System

Developed a comprehensive full-stack web application designed to minimize urban food waste by connecting donors with NGOs in real-time. The frontend is built using HTML5, CSS3, and JavaScript to provide a clean, responsive, and user-friendly interface for seamless navigation. On the backend, Java and MySQL ensure robust data processing and secure storage, managed through Maven and deployed via Apache Tomcat. The system features an automated donation workflow, location-based mapping, and a centralized dashboard for efficient resource tracking. This project demonstrates expertise in bridging social impact with scalable technology to ensure surplus food reaches the needy promptly.
